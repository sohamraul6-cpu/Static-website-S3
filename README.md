# Static-website-S3
# Hosted a static website on Amazon S3 using following steps
1) Created an Amazon Web Services (AWS) account and logged in from root user.
2) Created an S3 bucket named static-website-hosting-week-1.
3) Changed the properties by enabling ACL and allowing Block public access.
4) Started with the static website hosting using index.html as the homepage.
5) Changed permissions using custom json format.
6) Check the URL provided by S3 and achieved the desired output.
